Hardware Overview

The system required a way to identify students physically. Two pieces of hardware were chosen: a Raspberry Pi 3B to host the software and an ACR122U NFC reader to capture card taps via USB.

🖥️
Raspberry Pi 3B
Acts as the on-site server — runs rfid_reader.py, the Flask backend, and the SQLite database locally. No external server needed.
1.2 GHz quad-core 1 GB RAM Wi-Fi + USB Raspberry Pi OS 64-bit
📡
ACR122U NFC Reader
Reads 13.56 MHz ISO 14443 cards over USB. Exposes a standard PC/SC interface so no proprietary driver was needed — pyscard communicates via pcscd.
ISO 14443 A/B USB 2.0 PC/SC compliant
🪪
NFC Student Cards
MIFARE Classic 1K cards. Each stores a unique UID which the reader returns in response to the APDU command. No data is written to the card.
MIFARE Classic 1K 4-byte UID 13.56 MHz

Ongoing Evaluation

Integrating the ACR122U with the Pi proved the system could capture real NFC taps using standard, off-the-shelf hardware with no custom electronics. The hardest challenge was not the application code but the Linux driver stack — PC/SC permissions and missing build dependencies required several iterations to resolve. The integration testing table confirms all core components passed, with school Wi-Fi reliability and automatic boot startup identified as the two remaining risks to address before a full deployment.
